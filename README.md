# 132STA — Structural Analysis in Python

Teaching materials and Python utilities developed for the Structural Analysis (132STA) course at the Faculty of Civil Engineering, Czech Technical University in Prague.

## Scope and licence

This repository contains teaching code for linear, small-displacement, planar structural problems. It is not intended for engineering design or verification. Check modelling assumptions and results independently before professional use.

The Python source files are provided under the [MIT licence](LICENSE).
